# dotnet-kanban-assignment

# Running the App

## Command Line
0. From root directory
1. Change directory to `dotnet-kanban`  
2. run `dotnet run`
3. copy the address (e.g. `http://localhost:5140`) into a browsers address bar

## Visual Studio
0. From root directory
1. Change directory to `dotnet-kanban`  
3. enter `Ctrl + F5` (Start without debugging)
4. Open the output window `View -> Output`, select "ASP.NET Core Web Server" from the "Show output from" dropdown to see the console logs
5. copy the address (e.g. `http://localhost:5140`) into a browsers address bar
